## Segurança

O código de 4 dígitos é um **bloqueio visual**, nunca autenticação segura. O HTML público e os seus dados são visíveis a qualquer pessoa com o URL. Não adicionar segredos, identificadores internos do PC, ficheiros ou URLs privadas. Uma área verdadeiramente privada exige autenticação do lado do servidor, por exemplo Cloudflare Access.

## Limites

O mapa representa um inventário datado, não um monitor em tempo real. Não foram alterados repositórios de produção além desta página `site/mapa/`; nenhum lançamento musical, livro ou site de terceiro foi modificado.
