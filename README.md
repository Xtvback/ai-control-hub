# AI Control Hub

Private-first cloud automation workspace using GitHub Actions.

## Safety
- Never commit credentials, API keys or personal tokens.
- Workflows have read-only permissions by default.
- Initial workflow is manual only and changes no external systems.
- Existing repositories are not accessed or modified.

## First test
Open **Actions → Safe Cloud Smoke Test → Run workflow** and check the run succeeds.

See `docs/SECURITY.md` and `docs/ROADMAP.md` for safeguards and future phases.
