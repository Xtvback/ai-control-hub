# Static site demo

This demo is deliberately **not publicly deployed**. The repository is private.

## Preview

Open GitHub Actions > Static Site Preview Artifact, select Run workflow, and download the `static-site-preview` artifact from a successful run. Open `index.html` locally to inspect.

## Public deployment (future, requires explicit approval)

A public GitHub Pages site can be enabled after reviewing whether its content is safe to publish. GitHub Pages availability for private repositories depends on account plan and settings. A Cloudflare Pages deployment may require connecting a separate service and approving permissions.

Do not publish private source code, repository secrets, or sensitive files. Keep deployment disabled until approved.

## Cost

No API keys or paid AI services. GitHub Actions and artifact storage are subject to the account's free quotas.
